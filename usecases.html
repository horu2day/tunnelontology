    🔧 Use Case 3: 장비 사용 빈도 분석

    어떤 장비가 얼마나 자주 사용되는지 분석하여 장비 관리 계획을 수립합니다.

    📏 Use Case 4: 전진장 분석

    각 사이클의 전진장을 비교하고 통계를 계산합니다.

    -
    평균 전진장
    -
    최대 전진장
    -
    최소 전진장
    -
    총 전진장

    ⚡ Use Case 5: 효율성 지표 (m/h)

    사이클당 시간 대비 전진장 비율로 굴착 효율성을 측정합니다.

    사이클 전진장 (m) 소요시간 (h) 효율성 (m/h)

    🏗️ Use Case 6: 지보재 설치 통계

    각 사이클에서 설치된 지보재의 종류와 수량을 분석합니다.

    🔨 Use Case 7: 천공 구멍 분석

    사이클별 천공 구멍의 종류(심빼기공, 주변공, 보조공)와 수량을 분석합니다.
